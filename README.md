# The two-year game

An AI portfolio decision simulation (TAIL Unit A). Fifteen AI proposals, one budget, two years.

**Play it:** https://rajkumarreddy-lab.github.io/ai-opportunity/

- Runs entirely in the browser; no sign-in, no server, nothing is sent anywhere.
- Progress saves in the player's own browser, so they can stop between years.
- Best on a laptop or desktop with a current Chrome, Edge, Firefox or Safari.

The company, figures and outcomes are fictional.
